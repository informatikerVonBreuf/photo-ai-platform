# Contributing Guide — Photo AI Platform

Merci de contribuer au projet **Photo AI Platform** 🎉  
Ce document définit les règles à respecter pour garantir un développement propre,
collaboratif et sans erreurs.

---

## 👤 Rôles & responsabilités

### Project Owner / Tech Lead
- Définit la vision produit et les priorités
- Valide les choix techniques
- Valide les Pull Requests vers `dev` et `main`
- Garant de la qualité du code et de l’architecture

### Contributeurs (Frontend / Backend / ML / DevOps)
- Développent les fonctionnalités assignées
- Respectent les conventions Git et code
- Proposent leurs changements via Pull Requests

---

## 🌳 Organisation des branches

### Branches principales
- `main` → branche stable (démo, soutenance, release)
- `dev` → branche d’intégration
